## 2. 확정된 결정 (재논의 금지)

- 세계 = "AI 직원을 고용한 점주의 가게". 관통 문장: **제안은 AI, 판정은 세계, 확정은 사람** + 보완 **"사람이 승인한 정책 범위는 규칙이 자동 확정하고, 격상 건은 사람이 확정한다"**(sol 리뷰로 추가 — 소액 자동 승인과의 모순 해소, 규칙 대장 출처=점주가 그 승인의 물증).
- 한 단계 = 법 하나(4단계는 법 3개 예외 — 단위가 "프롬프트 파일 하나"). 태그 `stage-NN-start/-done`, 코드 변경 없는 단계는 `-done`만. 히스토리 재작성 금지, 태그 이동은 `stages/README.md`에 기록.
- AI 직원은 고정 fixture(채점). 실접속은 관찰용 병행 트랙 — "LLM이 속는가"는 측정 대상이 아니다.
- Django 안에 MCP 호스팅 안 함(별도 프로세스 stdio). 근거: `packages/django-itda/docs/벤치마킹-MCP-생태계.md` — mcp v2(FastMCP 삭제), fastmcp 4.x 기반 권고 B-1, django-mcp-server(v1 고정·정지) 기각.
- "Django가 FastAPI에 밀리는 기능 종합 패키지"는 **명시적 비목표**. 대신 비교 가이드 문서 1편(미작성).
- 이사 비용표는 구현 diff / 준비 비용 분리, LOC는 효율 증명이 아님.
- **5단계 확정(2026-09-06)**: 승인 시점 기한 재검사는 **하지 않는다**(판정 시점 = 신청 시점, 바꾸려면 `REFUND-001@v2`). 같은 멱등키·다른 내용은 최초 내용 우선(충돌 검사 없음). DENY·ALREADY 는 저장하지 않는다. `select_for_update` 는 SQLite 에서 행 잠금이 붙지 않음을 실측만 한다. 경합 테스트는 `live_server` 가 아니라 **파일 테스트 DB + 스레드 + Barrier(잠금 밖, `mock.patch`)** 로 — 인메모리 shared-cache 에서는 잠금 오류가 먼저 난다. `IMMEDIATE`·WAL·timeout 은 빈도 완화이지 소거 증명이 아니다.
- 이름·배치: 교육 프로젝트 **itda-django**(저장소 루트) / 도구면 패키지 **django-itda**(`packages/django-itda/`, 임포트 `django_itda`). 별도 저장소는 사용자가 하나뿐인 지금은 이르다고 판단해 합쳤다(2026-09-06) — 두 번째 사용자나 배포 시점에 디렉터리째 분리.
