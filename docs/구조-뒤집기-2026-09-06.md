`packages/` 디렉터리는 사라진다.

## 원칙

1. **`git mv` 로만 옮긴다.** 내용 변경은 경로·문구 갱신에 한정한다. 코드 로직·테스트·마이그레이션 변경 0.
2. **테스트 81개는 `examples/itda-django/` 에서 `uv run pytest` 로 그대로 통과**해야 한다. 루트 `.venv` 하나를 공유한다
   (uv workspace — 멤버 디렉터리에서 `uv run` 하면 루트 venv 를 쓴다).
3. `db.sqlite3` 는 `examples/itda-django/db.sqlite3` 가 된다(`config/settings.py` 의 `BASE_DIR` 기준이라 코드 변경 없음).
   루트 `.gitignore` 의 `db.sqlite3` 패턴은 하위에도 걸린다.
4. 이동 커밋은 `stage-05-done`(`23d3176`) 뒤, `stage-06-start` 앞에 놓인다. 태그는 하나도 옮기지 않는다.
