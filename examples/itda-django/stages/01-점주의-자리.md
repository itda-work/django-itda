# 1단계 — 점주의 자리

이 단계에서 **학생이 쓰는 코드는 0줄**이다. 화면 두 개와 계정 두 개만 오간다.

- **에이전트 콘솔** <http://127.0.0.1:8000/agent/> — AI 직원(`ai-staff`)이 앉는 자리. 제안한다.
- **admin 승인 큐** <http://127.0.0.1:8000/admin/orders/refund/> — 점주(`owner`)가 앉는 자리. 확정한다.

볼 것은 한 문장이다. **AI가 아무리 제안해도, 점주가 누르기 전엔 세계가 안 움직인다.**

## 준비

```bash
just reset-db
just run
```

로그인 상태가 섞이면 아무것도 안 보이므로 **창을 두 개로 분리**한다.

- 일반 창 → <http://127.0.0.1:8000/agent/> → `ai-staff` / `ai1234`
- 시크릿 창(또는 다른 브라우저 프로필) → <http://127.0.0.1:8000/admin/> → `owner` / `owner1234`

`owner`는 이제 **superuser가 아니다.** 0단계에서는 전능했지만, 이 단계부터 점주는
`점주` 그룹이 준 권한만큼만 할 수 있다. superuser는 `admin` / `admin1234` 로 따로 뺐다.

| 계정 | 비밀번호 | 자리 | 할 수 있는 일 |
|---|---|---|---|
| `ai-staff` | `ai1234` | 에이전트 콘솔 | 주문 접수, 환불 **제안** |
| `owner` | `owner1234` | admin | 환불 **승인·거부** |
| `admin` | `admin1234` | admin | 전부(교육용 뒷문) |

## 명령 — 4비트를 순서대로

콘솔의 카드를 위에서부터 하나씩 누른다. 누를 때마다 **아래 상태 패널의 배지가 어떻게 변하는지**를 본다.

**① 주문 접수** — AI 직원이 alice의 장바구니로 주문을 만든다.
누르는 즉시 새 주문이 `결제 대기`로 생긴다. 콘솔에 *세계가 받아들였다 ✅*.
아무도 승인하지 않았는데 커밋됐다. **AI 직원의 권한 안에 있는 일이기 때문이다.**

**② 환불 제안** — `SEED-0002`(3일 전, 결제 완료)를 환불하자고 제안한다.
콘솔에 *점주 승인 대기 ⏳*. 그리고 `SEED-0002`의 상태 배지를 확인한다 —
**여전히 `결제 완료`다.** 환불 제안이 생겼을 뿐, 주문은 1밀리미터도 안 움직였다.

**③ 승인 확인** — 콘솔에서는 할 게 없다. 시크릿 창(점주)으로 간다.

1. admin → **환불** 목록. 기본 필터가 `제안됨`이라 방금 올라온 제안이 보인다.
2. 체크박스를 켜고 액션 **`선택한 환불을 승인`** → 실행.
3. 콘솔로 돌아와 **새로고침**. `SEED-0002`가 `취소`로 바뀌었다.

세계가 움직인 시각 = 점주가 누른 시각이다.

**④ 거부 확인** — 콘솔에서 `SEED-0003`에 대한 두 번째 제안(*단순 변심*)을 만든다.
점주 창에서 이번엔 액션 **`선택한 환불을 거부`**.
콘솔을 새로고침하면 `SEED-0003`은 **`결제 완료` 그대로**, 환불만 `거부`로 남는다.

거부는 "없던 일"이 아니라 **기록**이다. 환불 상세에서 *결정자*가 `owner`로 찍혀 있는지 확인한다.

## 의도적 실패

콘솔 맨 아래 빨간 버튼 — **[AI 직원으로 직접 승인 시도]**.

AI 직원이 자기가 올린 제안을 자기가 승인해 버리는 것이다. 눌러 본다.

```
403 — 세계가 거부했다
권한이 없다.
```

주문 상태도, 환불 상태도 그대로다. 프롬프트로 부탁한 것이 아니고, 화면에서 버튼을 숨긴 것도 아니다.
**서버가 거부했다.**

여기서 멈추고 스스로 답해 본다.

> 이 403을 만든 코드를 나는 오늘 한 줄도 쓰지 않았다. **그럼 누가 막았나?**

## 수정

**없다.** 이 단계에서 학생이 고칠 코드는 없다.

방금 목격한 것 — 요청자와 승인자를 계정으로 갈라놓고, 권한 없는 호출을 서버가 403으로 끊고,
누가 확정했는지가 자동으로 기록되는 것 — 은 전부 **이미 거기 있었다**.

그 "이미 있었다"의 정체를 뜯어보는 것이 2단계다. 지금은 질문만 들고 넘어간다.

## 검증

```bash
just test 01
```

9개 테스트가 통과해야 한다. 시작 상태에서는 같은 테스트가 **전부 실패한다**.

```bash
just test 01           # 실패를 눈으로 확인

git diff stage-01-start stage-01-done    # 정답 해설
```

## 제출물

`stages/제출물/01-<본인이름>.md` 로 만들어 낸다.

1. **스크린샷 4장** — 4비트 각각의 순간.
   - ① 주문 접수 직후 콘솔 (*세계가 받아들였다 ✅*)
   - ② 환불 제안 직후 콘솔 — **`SEED-0002`가 아직 `결제 완료`인 배지가 함께 보이게**
   - ③ 점주 승인 후 콘솔 — `SEED-0002`가 `취소`
   - ④ 거부 후 환불 상세 — `상태=거부`, `결정자=owner`
2. **스크린샷 1장** — 403 화면.
3. **한 줄** — 세계가 언제 움직였고, 언제 안 움직였나. 시각이 아니라 **누구의 클릭**으로 답한다.
4. **질문 하나** — "그럼 누가 막았나?"에 대한 지금 시점의 추측. 틀려도 된다. 2단계에서 답을 맞춰 본다.
